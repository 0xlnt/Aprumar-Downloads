# Aprumar — downloads

Este repositório contém somente os instaladores e os arquivos de atualização do Aprumar. O código-fonte permanece em um repositório privado.

Os instaladores publicados aparecerão na página [Releases](https://github.com/0xlnt/Aprumar-Downloads/releases). Ainda não há uma versão pública pronta para uso: a atualização do banco de dados precisa ser concluída antes do primeiro lançamento aqui.

Baixar o programa não concede acesso aos dados. Novas contas dependem da aprovação de um administrador e das regras de domínio de e-mail configuradas no aplicativo.

No Windows, execute o instalador `.exe`. No Linux, baixe o `.AppImage`, marque-o como executável e abra-o. As atualizações posteriores serão verificadas pelo próprio aplicativo, desde que ele tenha sido instalado a partir de uma versão conectada a este canal público.
